# geometric_lib

## Общее описание

`geometric_lib` — учебная библиотека на Python для вычисления площадей
и периметров простых геометрических фигур: круга, квадрата и прямоугольника.

Библиотека не имеет внешних зависимостей (кроме стандартного `math`)
и может использоваться как набор утилит или как основа для более
крупного проекта.

## Состав проекта

| Файл            | Назначение                              |
|-----------------|-----------------------------------------|
| `circle.py`     | площадь и периметр круга                |
| `square.py`     | площадь и периметр квадрата             |
| `rectangle.py`  | площадь и периметр прямоугольника       |
| `docs/`         | документация проекта                    |

## Поддерживаемые формулы

### Площадь (Area)
- Circle:    S = πR²
- Rectangle: S = ab
- Square:    S = a²

### Периметр (Perimeter)
- Circle:    P = 2πR
- Rectangle: P = 2a + 2b
- Square:    P = 4a

## Быстрый старт

```python
import circle

print(circle.area(5))        # 78.5398...
print(circle.perimeter(5))   # 31.4159...
